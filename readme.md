# Laundry Service Page

A simple  Laundry Service landing page created using **HTML** and **CSS**. This project focuses on building a clean user interface while practicing CSS styling, layout, fonts, colors, and responsive design.

## Features

* Clean and modern design
* Responsive layout
* section and nav tag used
* Simple and easy-to-read code

## Technologies Used

* HTML
* CSS


## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Double-click `index.html` or open it in any web browser.

## Purpose

This project was created to practice front-end web development concepts such as HTML structure, CSS styling responsive design.
